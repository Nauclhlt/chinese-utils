# ゲーム拡張開発計画 (GAMES_PLAN.md)

## 1. 概要
既存の中国語CALL学習Webアプリに対し、学習機能を持たない一般のゲームとしても十分に楽しめるクオリティを備えた4種類の本格ゲームコンテンツを追加する。
全ゲームは完全静的（GitHub Pages対応）、バックエンド・有料API不要で動作し、学習履歴・SRS復習・苦手分析と有機的に連携する。

## 2. 4大ゲーム設計

### 2.1 中国語ノベルゲーム『雨霁星语（あめあがりのほしのことば）』
- **ジャンル**: 青春・百合（女の子同士の繊細な関係性）・静謐SF・感動系（プレイ時間目安45〜90分相当の5章構成・エンディング3種）
- **世界観**: 梅雨明け前後の海辺の旧天文台図書室を舞台に、少しだけ過去の光（残響星象）が視えてしまう少女・苏晚星（スー・ワンシン）と、大学天文同好会の記録係・林澄（リン・チェン）、幼馴染の顾知夏（グー・ジーシア）が織りなす静かで透明感のある物語。
- **エンジン仕様**: JSONシナリオ完全データ駆動。文字送り、背景/立ち絵/表情差分/イベントCGフェード演出、Web Audio APIオリジナルBGM/雨音環境音/効果音、選択肢分岐、フラグ管理、手動6スロットセーブ/ロード、クイックセーブ/ロード、オートセーブ、オートモード、既読スキップ、バックログ、UI非表示、CGギャラリー、エンディング図鑑、章選択。
- **任意学習補助**: ピンインON/OFF、日本語訳ON/OFF、1文翻訳表示、単語クリック辞書＆「復習帳へ追加」（教材外語彙として区別）、口語/慣用/文法解説パネル、Web Speech読み上げ、章終了後の任意ミニ復習。

### 2.2 声調リズムゲーム『声律星轨 (Tone Beat Orbit)』
- **核心設計**: 第1声・第2声・第3声・第4声・軽声の5キー（またはタッチ5パッド）に対応。ノーツは**中央単一軌道**をニュートラル色で流れ、出現位置や色で正解がバレない仕様。表示される漢字／無標ピンイン（意味・漢字補助付きで一意特定）／音声から声調を読み取り、判定ラインに合わせてキーを押す。
- **音と同期**: `AudioContext.currentTime` を基準にした高精度スケジュール同期（4曲の完全オリジナルシンセ/ドラム楽曲、96〜148 BPM、Easy/Normal/Hard）。音声モードはWeb Speechの遅延を考慮しタイミング強制のないターン制で実装。練習モード（タイミング判定なし）完備。
- **分析**: Perfect/Great/Good/ToneMiss/Miss判定、コンボ、S/A/B/Cランク、声調別正答率、変調（第3声連続・一・不）解説、ミス単語のSRS復習連携。

### 2.3 文法訂正ゲーム『语病猎手 (Grammar Hunter)』
- **核心設計**: 日本語話者が陥りやすい誤文を「スキャン→誤り箇所特定→8形式の適切な方法で修正」するエディトリアル・パズルゲーム。
- **8形式**: `spot`（誤り箇所発見）、`replace`（語句置換）、`delete`（不要語削除）、`insert`（不足語追加）、`reorder`（語順修正）、`rewrite`（文全体書き換え）、`judge`（正誤判定）、`multi-error`（複数誤り訂正）。
- **ゲームモード**: 全12ステージ（312問以上、うち3ボスステージは複数文法複合）、ライフ制チャレンジ、タイムアタック、無制限練習、苦手文法優先復習ステージ。既存文法IDと連動しSRSへ反映。

### 2.4 ピンイン漢字変換・語順パズル『字序工坊 (Pinyin Word Forge)』
- **核心設計**: シャッフルされたピンイン語句カードそれぞれに簡体字を直接入力し（中国語IMEの `isComposing` 変換確定Enterと解答確定を完全分離）、ドラッグ＆ドロップ・クリック/タップ・キーボードで語順を組み立てて中国語文を完成させる。
- **評価・モード**: 漢字変換精度と語順精度を分離評価。複数許容解答に対応し、自由入力不一致時は自己確認フローを提供。日本語ヒントON/OFF、3段階ヒント、色分け文法構造解説、7モード（基本・文法別・タイムアタック・エンドレス・ボス・苦手復習・大学試験再現モード＝全問終了後一括採点）、12ステージ312問以上。

## 3. 完成条件
1. 4ゲームすべてがタイトル→プレイ→リザルト→再プレイまで完結して動作すること。
2. 既存学習サイトの全機能が維持され、ゲームの学習成果が `ReviewPage` 等と連携すること。
3. 検証スクリプト・単体テスト・プロダクションビルド・Playwright実ブラウザプレイテストがすべて合格すること。

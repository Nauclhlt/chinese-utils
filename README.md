# 中国語CALL学習スタジオ（京都大学中国語CALL教材準拠）

京都大学中国語部会編「中国語CALL教材 －上海・2026－」の学習シラバス・文法体系を参考に、日本語を母語とする大学生が初級〜初中級の中国語を体系的に学習できる完全静的なWebアプリケーションです。

- 参考教材: https://hanyujiaocai.jinkan.kyoto-u.ac.jp/2018shanghai/2018CALL/index.html
- **著作権について**: 本アプリケーションの解説・例文・語彙説明・練習問題・作文問題はすべて独自に作成されたものです。参考教材の本文・例文・単語表・画像・音声の転載は行っていません。原典確認用リンクとして各課・各文法事項から参考教材URLへ移動できます。

---

## 主な機能

1. **ホーム・学習ダッシュボード**: 学習範囲（第1課〜第N課まで／任意選択）の設定、進捗可視化、本日の復習対象、最近間違えた問題、学習履歴、前回の続きへの導線。
2. **課別学習（全22課）**: 各課の学習目標、文法事項、関連語彙、独自例文、課内練習、確認テスト（各課10問以上）。
3. **文法辞典・類似表現比較・学習マップ**: 分類別・課別・日本語/中国語/ピンイン/例文横断検索、色分け構文図、10テーマの比較表（了/过/着、不/没、的/地/得、会/能/可以 など）、前提関係マップ、印刷用まとめシート。
4. **単語帳**: 検索・絞り込み・並べ替え・お気に入り・習熟度管理、中国語/ピンイン/日本語訳の列非表示切替、独自単語登録、CSV / Anki用TSVエクスポート。
5. **フラッシュカード**: 6方向出題（中→日、日→中、中→ピンイン、ピンイン→中、中→声調、音声→中・日）＋SM-2ベースの間隔反復（SRS）。
6. **ピンイン・声調練習**: 7形式のドリル（声調記号/数字表記/ü/v/u:/軽声5を同等に判定）＋声調変調（第3声連続、「一」「不」の変調）解説。
7. **文法練習**: 穴埋め、選択、語順整序（タイル組立）、誤文訂正、正誤判定、類似表現使い分け、複数文法応用、独自問題登録。
8. **中国語作文練習**: 翻訳・指定文法作文、使用文法表示/試験対策非表示モード、3段階ヒント、許容解答判定、横並び比較＆文字差分ハイライト、色分け構文解説、典型誤答、自己採点・再出題。
9. **音声・リスニング**: Web Speech API による中国語読み上げ、再生速度調整、ディクテーション、意味選択（非対応環境では自動検知して案内表示）。
10. **総合テスト・データ管理**: 範囲/形式/難易度/制限時間指定テスト、弱点分析、JSONエクスポート・インポート（検証・破損対処）。

## 必要な開発環境

- Node.js 20.x 以上（推奨: v22.x）
- npm 10.x 以上
- （教材クロールスクリプトを実行する場合のみ）Python 3.10 以上

## GitHub Pages への公開

本リポジトリには `.github/workflows/deploy.yml` が含まれています。

1. GitHub 上にリポジトリを作成し、コードをプッシュします（`main` または `master` ブランチ）。
2. GitHub リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更します。
3. プッシュをトリガーに自動的にデータ検証・テスト・ビルド・GitHub Pages へのデプロイが実行されます。
4. **リポジトリ名を変更する場合**: `vite.config.ts` が相対ベースパス (`base: './'`) かつ `HashRouter` を使用しているため、設定ファイルを書き換えることなく任意のリポジトリ名（`https://<user>.github.io/<repo-name>/`）でそのまま動作します。

## 学習データの追加・修正方法

学習データはアプリケーションのコードと分離されており、`src/data/` 配下の JSON ファイルを編集するだけで UI に自動反映されます（UIコードの編集は不要です）。

### データの追加・修正手順

1. **文法事項の追加・修正**: `src/data/grammar/L01.json` 〜 `L22.json`（または補足モジュール `P00.json`）を編集します。新しい課ファイルや文法エントリを追加した場合は、`src/data/lessons.json` の `grammarIds` にも登録してください。
2. **語彙データの追加・修正**: `src/data/vocab/L01.json` 〜 `L22.json`、または登場課が教材で確認できない補足語彙は `src/data/vocab/supplement.json`（`lessonId: null`, `source: "supplement"`）を編集します。
3. **練習問題・作文問題の追加・修正**: `src/data/exercises/L01.json` 〜 `L22.json` および `src/data/compositions/L01.json` 〜 `L22.json` を編集します。スキーマ規約は [DATA_SCHEMA.md](./DATA_SCHEMA.md) を参照してください。
4. **検証と網羅性レポート更新**:
   ```bash
   npm run validate
   npm run coverage
   npm run check
   ```

## トラブルシューティング

- **音声読み上げボタンが無効になっている / リスニングが動作しない**:
  お使いの OS・ブラウザに中国語（`zh-CN`）の音声合成エンジンが入っていない場合、アプリが自動検知して音声機能を安全に無効化します。Windows では「設定 → 時刻と言語 → 音声認識 → 音声の追加」から「中国語（簡体字、中国）」を追加してブラウザを再起動すると有効になります。
- **GitHub Pages でリロードすると 404 になる**:
  本アプリは `HashRouter`（`#/...`）を使用しているため通常は 404 になりません。URL に `#` が含まれていることと、`vite.config.ts` の `base: './'` が維持されていることを確認してください。
- **Playwright がローカルで起動しない**:
  `playwright.config.ts` は Windows 上の Microsoft Edge (`channel: 'msedge'`) を使用する設定になっています。Chromium を使う場合は `npx playwright install chromium` を実行し、`playwright.config.ts` の `channel` 設定を調整してください。
